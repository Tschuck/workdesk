# Use cases

Each page is a short walkthrough with the steps in order. Names in *italics* are buttons, menus and settings in the app.

- [Set up and start working](/use-cases/setup): a Project, a Todo, your first WorkDesk.
- [Configure the app](/use-cases/configuration): theme, tabs, quitting, waiting, environment variables.
- [Work in a WorkDesk](/use-cases/working-in-a-workdesk): a normal day with several desks.
- [Review a pull request](/use-cases/reviewing-a-pull-request): from the request to your verdict.
- [From approval to merge](/use-cases/merging): knowing when a pull request is ready, and combining WorkDesks.
- [Several products with Profiles](/use-cases/multiple-profiles): keep clients or products apart.
- [The browser](/use-cases/browser-behavior): how pages open, sessions, blocking.
- [Work with Claude](/use-cases/working-with-claude): Accounts, hooks, Signals, skills.
- [Save resources](/use-cases/saving-resources): park, hibernate, measure.
