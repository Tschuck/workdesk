# Implementation Plan

> Generated: 2026-10-27
> Goal: Build WorkDesk v1 (macOS Electron app) as designed in CONTEXT.md and docs/adr, in vertical slices that each leave a runnable app.

## Steps


## Done

- [x] **Build the domain core and Status Repo** — Pure, tested modules for WorkDesk, Kind, Stage, Signal, WorkDesk order and presence, plus a store that reads/writes `workdesk-status` (todos.json, desks/, archive/), `git init`s it and auto-commits debounced (~60 s) with optional push; done when unit tests cover ordering, Stage rules and commit/push behaviour against a fake git.
- [x] **Scaffold the Electron app** — Electron + TypeScript + Vite + React + Vitest with main/preload/renderer split, `npm run dev`, `npm test` and `npm run build`; done when an empty window opens and one smoke test passes.
- [x] **Add Projects, worktrees and clearing** — Register a Project (bare clone in `.projects/` or existing clone), create a Branch worktree per the folder layout with linked files (`.env`), and implement the clear flow (pre-flight check, notes archive, worktree removal, never delete branches) behind a git interface; done when integration tests on temp repos pass.
- [x] **Build Backlog and Today and start Plain WorkDesks** — Todo CRUD with Topics as filter tags, Backlog and Today views, multi-select "Start WorkDesk" that creates a Plain WorkDesk; done when a Todo can go Backlog → Today → WorkDesk in the UI.
- [x] **Build the sidebar tree** — Sidebar with WorkDesk > Project > Branch tree in WorkDesk order, drag-and-drop manual priority, Signal badges, dimmed waiting Stages, `⌘1…9` and `⌘↑/↓`, order frozen during drag; done when order rules show correctly with seeded data.
- [x] **Add Terminal Panes and Tabs** — xterm.js + node-pty attached to one tmux session per WorkDesk (window per Pane), named Tabs, horizontal/vertical split layout tree persisted in `.workdesk/state.json`; done when a layout survives an app restart.
- [x] **Add the Editor Tab** — Window-control interface (`showEditor/hideEditor/closeEditor`) with a macOS implementation, one multi-root `.code-workspace` per WorkDesk kept in sync with its Branches, and focusing a Branch's folder from the sidebar; done when switching WorkDesks shows/hides the right VS Code window quickly.
- [x] **Add Browser Panes** — `<webview>` Panes with one shared persistent session partition, mixable with Terminals in a Tab layout, URL/title persisted; done when a GitHub login survives restart and across WorkDesks.
- [x] **Add Claude hooks and Signals** — `workdesk hook <event>` CLI over a unix socket, consented install into every registered Claude config dir (with uninstall), cwd-to-Branch matching, Claude and command-finished (OSC 133) Signals, jump-to-Signal and ~2 s focus acknowledgement, self-clearing, `claude --resume` restore; done when a real Claude session raises and clears Signals on the right Branch.
- [x] **Add the GitHub Source and Review WorkDesks** — Source interface, Integration page with Candidates (add to Backlog/Today, skip, tracked), GitHub PR source via `gh` or PAT in the Keychain, Review WorkDesk from a PR with Stage derived from reviews, ~60 s polling for re-review, comments, CI and merged; done when a PR becomes a Review WorkDesk end to end.
- [x] **Add Ticket WorkDesks, Notion Source and Stacks** — Notion source with token in Keychain and configurable database/mapping, Ticket WorkDesk (Projects picked, ticket-ID branch name), "Add branch to Stack" with PR base = previous Branch and confirm-only restack; done when a 3-branch Stack shows as a tree with correct bases.
- [x] **Add parking and package the app** — Explicit park/reactivate (state file, tmux kill, restore), first-run checks for tmux/git/code, unsigned `.dmg` via electron-builder and a GitHub Release workflow; done when a parked WorkDesk restores its Tabs, Panes and Claude sessions and the `.dmg` installs.
